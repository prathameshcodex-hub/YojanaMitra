# YojanaMitra 🇮🇳

**Team Name:** Bug Slayers

**Project:** Government Scheme Eligibility Reverse-Matcher

## About the Project
YojanaMitra helps people discover Indian government schemes that may match their profile. It shows potential scheme matches, eligibility reasons, and documents users may need.

## Key Features
- Profile-based government scheme matching
- Eligibility and rejection reasons
- Missing document checklist
- Official scheme links
- FastAPI backend
- Simple web interface
- AI-assisted PDF information extraction

## Schemes Included
1. PM-KISAN
2. Kisan Credit Card (KCC)
3. PM-Kisan Maandhan Yojana (PM-KMY)
4. Majhi Ladki Bahin Yojana
5. Swarnima Scheme
6. Pradhan Mantri Awas Yojana–Urban (PMAY-U)
7. PM Vishwakarma

## Technology Used
- Python
- FastAPI
- HTML, CSS and JavaScript
- JSON
- Ollama with Qwen3 1.7B

## How to Run
Open PowerShell in the YojanaMitra folder and run:

```powershell
.\backend\venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --reload
```

Then open `http://127.0.0.1:8000/` in your browser.

## Disclaimer
YojanaMitra provides preliminary eligibility guidance based on its current dataset. Matching results do not guarantee official eligibility or benefits. Users should verify details on official government portals.
